# Context

Notes, decisions, and references kept between Claude Code sessions so future
sessions can pick up where prior ones left off.

Suggested files:
- `overview.md` — what this project is and why
- `decisions.md` — choices made and the reasoning behind them
- `todo.md` — outstanding work and open questions
- `references.md` — links, docs, and external resources

Keep entries dated and concise. This folder is tracked in git so context
syncs across machines.
